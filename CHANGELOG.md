# История изменений

## 1.1.0

- Текущая рабочая версия перенесена под название LipatoS.
- Для обычных игроков оставлены только вкладки «Описание» и «Функции».
- Вкладки «Подробности» и «Эффекты» скрыты.
- Добавлено автоматическое переключение на «Описание», если открыта скрытая вкладка.
- В меню функций игрокам запрещены редактирование, дублирование и удаление.
- Для ГМ и Assistant GM интерфейс остаётся без изменений.
