# LipatoS - Вкладки предметов для игроков

Модуль для **Foundry Virtual Tabletop** и системы **D&D 5e**, который упрощает интерфейс предметов для обычных игроков.

При открытии предмета игрокам остаются только вкладки **«Описание»** и **«Функции»**. Вкладки **«Подробности»** и **«Эффекты»** скрываются. В меню функций также недоступны редактирование, дублирование и удаление.

## Версия

**1.1.0**

## Совместимость

- Foundry VTT: **14**
- D&D 5e

## Возможности

- оставляет игрокам вкладку **«Описание»**;
- оставляет игрокам вкладку **«Функции»**;
- скрывает вкладку **«Подробности»**;
- скрывает вкладку **«Эффекты»**;
- если игрок оказался на скрытой вкладке, автоматически переключает его на **«Описание»**;
- в меню функций запрещает игрокам редактирование, дублирование и удаление;
- безопасные пункты меню функций остаются доступными;
- для ГМ и Assistant GM интерфейс предмета остаётся без изменений.

## Установка

В Foundry VTT откройте **Add-on Modules → Install Module** и вставьте ссылку на манифест:

`https://raw.githubusercontent.com/Lipatosha/LipatoS-item-tabs-player/main/module.json`
